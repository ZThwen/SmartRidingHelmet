# 最终演示检查清单

> 模拟完整骑行流程：启动 → 连接 → 骑行 → 控制 → 报警 → 电源 → 导航 → 结束

## 前置条件
- [ ] NUCLEO-F413ZH 板子供电正常
- [ ] EC200U 4G 模块天线连接
- [ ] 手机安装微信小程序或 NRF Connect

## 演示场景

### 1. 系统启动
- [ ] 所有 21 模块初始化成功
- [ ] 终端输出 "✅ 系统就绪，21 个模块在线"
- [ ] LCD 显示欢迎界面

### 2. BLE 连接
- [ ] 手机可搜索到 `SmartHelmet-66ccff`
- [ ] 连接成功，终端显示 BLE 已连接
- [ ] 小程序收到状态回推

### 3. 骑行控制
- [ ] 开灯成功（语音/BLE/按键）
- [ ] 灯光自动模式响应环境光照
- [ ] 传感器数据实时推送到手机

### 4. 远程控制
- [ ] 灯光亮度调节（+-5 档）
- [ ] 音量调节
- [ ] 状态查询（TTS 播报）

### 5. 音频调度（AudioService）
- [ ] 导航 TTS 播报正常
- [ ] 报警触发时打断导航 TTS（优先级正确）
- [ ] 控制指令 TTS 在导航 TTS 播完后排队播放
- [ ] 报警期间非报警 TTS 被拒绝

### 6. 碰撞报警
- [ ] SOS 触发 → LED 快闪 + SOS 音 + TTS
- [ ] BLE 推送报警到手机

### 7. 取消恢复
- [ ] 取消报警 → LED 灭 + 音停
- [ ] 状态恢复到报警前

### 8. 电源切换
- [ ] 省电模式 → 传感器降频
- [ ] 正常模式 → 恢复全速
- [ ] TTS 播报提示

### 8.5 低电量自动省电
- [ ] 电池电量降至 Level 2 → 自动切换 SUSPENDED
- [ ] TTS 播报"当前电量不足，请及时充电"
- [ ] ControlService 回推电源状态到小程序
- [ ] 手动切换 ACTIVE 后清除 auto_suspended 标记

### 8b. 电池监控
- [ ] 小程序显示电量档位（5/4/3/2/1/0）
- [ ] 低电量时 BLE 推送含 bat 字段
- [ ] 启动时前 3 次采样不做省电决策

### 9. 导航引导
- [ ] BLE 发送导航指令 → TTS 播报
- [ ] 转弯提示正确
- [ ] 到达目的地提示

### 10. 系统停止
- [ ] 关灯成功
- [ ] 系统可安全停止
