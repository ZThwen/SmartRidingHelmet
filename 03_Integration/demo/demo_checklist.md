# 最终演示检查清单

> 模拟完整骑行流程：启动 → 连接 → 骑行 → 控制 → 报警 → 电源 → 导航 → 结束

## 前置条件
- [ ] NUCLEO-F413ZH 板子供电正常
- [ ] EC200U 4G 模块天线连接
- [ ] 手机安装微信小程序或 NRF Connect

## 演示场景

### 1. 系统启动
- [ ] 所有 17 模块初始化成功
- [ ] 终端输出 "✅ 系统就绪，17 个模块在线"
- [ ] LCD 显示欢迎界面

### 2. BLE 连接
- [ ] 手机可搜索到 `SmartHelmet-66ccff`
- [ ] 连接成功，终端显示 BLE 已连接
- [ ] 小程序收到状态回推

### 3. 骑行控制
- [ ] 开灯成功（语音/BLE/按键）
- [ ] 灯光自动模式响应环境光照
- [ ] 传感器数据实时推送到手机

### 4. 远程控制
- [ ] 灯光亮度调节（+-5 档）
- [ ] 音量调节
- [ ] 状态查询（TTS 播报）

### 5. 碰撞报警
- [ ] SOS 触发 → LED 快闪 + SOS 音 + TTS
- [ ] BLE 推送报警到手机

### 6. 取消恢复
- [ ] 取消报警 → LED 灭 + 音停
- [ ] 状态恢复到报警前

### 7. 电源切换
- [ ] 省电模式 → 传感器降频
- [ ] 正常模式 → 恢复全速
- [ ] TTS 播报提示

### 8. 导航引导
- [ ] BLE 发送导航指令 → TTS 播报
- [ ] 转弯提示正确
- [ ] 到达目的地提示

### 9. 系统停止
- [ ] 关灯成功
- [ ] 系统可安全停止
