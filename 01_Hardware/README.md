# 电源检测拓展板 (Power Detection Expansion Board)

## 📝 项目简介
本项目为“电源检测拓展板”的硬件原理图设计文件（版本 V1.0）。该拓展板主要用于电源信号的输入保护、滤波以及电压分压检测，适用于需要监测外部电源电压、进行电源信号调理或射频/电源混合信号采集的嵌入式系统项目。

## ✨ 主要特性
- **多重输入保护**：具备防反接、防浪涌及过流保护功能，大幅提高系统运行的稳定性。
- **高效输入滤波**：多级电容滤波设计，有效滤除电源输入端的高频噪声和纹波。
- **精准分压检测**：专用的电阻分压网络，将输入电压按比例衰减，转换为微控制器 ADC 可安全采集的电压范围。
- **标准化接口**：采用 SMA 接口及标准排针，方便与外部设备及主控板进行可靠连接。

## ⚙️ 电路模块说明

### 1. 输入保护电路
- **防反接保护**：采用 `SS34` (3A/40V) 肖特基二极管 (**D3**)，防止电源正负极接反损坏后级电路。
- **防浪涌/静电保护**：采用 `SMF24CA` TVS 瞬态抑制二极管 (**D1**)，有效吸收浪涌电压和 ESD 静电，保护后级敏感器件。
- **过流保护**：串联保险丝 (**F1**)，在发生短路或严重过流时切断电路。

### 2. 输入滤波电路
- 采用多级电容组合进行电源去耦和滤波，确保检测信号的纯净度：
  - 大容量储能/低频滤波：**C5** (22µF)
  - 中高频滤波：**C6** (1µF)
  - 高频噪声滤除：**C1, C2, C3, C7** (均为 100nF)

### 3. 分压检测电路
- 由 **R1** (1KΩ) 和 **R2** (3.9KΩ) 组成电阻分压网络。
- **功能**：将输入的较高直流电压按比例衰减（分压比约为 1:4.9），输出至主控芯片的 ADC 引脚进行电压采样检测。

## 🔌 接口说明
- **RF1 (KH-SMA-KE-Z)**：SMA 连接器接口，用于外部电源或信号的输入。（*注：此处使用 SMA 接口可提供极佳的物理连接稳固性或用于特定高频信号检测*）。
- **H1, H2, H3**：标准排针接口，用于输出 `VCC` 或连接至主控板的检测引脚。

## ⚠️ 使用注意事项
1. **输入电压限制**：由于使用了 24V 的 TVS 管 (D1) 和 40V 的肖特基二极管 (D3)，请确保**最大持续输入直流电压不超过 24V**（建议工作在 20V 以内以留有余量），以免击穿保护器件。
2. **分压电阻功耗**：在较高电压输入时，R1 和 R2 会产生一定的静态功耗。若输入电压接近 24V，请核算电阻功率，必要时在 PCB 布局时选用 0805 或 1206 等较大封装的电阻。
3. **SMA 接口极性**：RF1 为 SMA 接口，若用于电源输入，接线或制作线缆时请务必确认中心针脚与外壳的极性，避免短路。
