# MicroPython 固件编译操作手册

## 一、环境准备（已完成）

已安装：
- MSYS2（`C:\msys64`）
- ARM 工具链（`C:\msys64\opt\arm-gnu-toolchain-13.3.rel1-mingw-w64-i686-arm-none-eabi\`）
- Python、make、git

## 二、添加/修改自定义模块

### 模块放在哪
你的 Python 模块放在：
```
micropython/lib/micropython-lib/micropython/smartcore/
├── core/           ← 核心框架（Base_Module, config, Event_Bus）
├── Drivers/        ← 硬件驱动（sensor, actuator, interface, network）
└── Modules/        ← 业务服务（alarm, ble, collision 等）
```

### 添加新模块步骤
1. 把 `.py` 文件复制到对应目录
2. 编辑 `smartcore/manifest.py`，在 `freeze()` 的文件列表中添加新文件名
3. 重新编译

### manifest.py 示例
```python
freeze("$(MPY_LIB_DIR)/micropython/smartcore", (
    "core/Base_Module.py",        # 格式：目录/文件名.py
    "Drivers/sensor/imu.py",
    "Modules/alarm_service.py",
    # 新模块加在这里
))
```

**重要**：路径必须带目录前缀（如 `core/Base_Module.py`），不能只写文件名。

## 三、编译固件

### 打开 MSYS2 MINGW64 终端
开始菜单 → MSYS2 MINGW64

### 执行编译（复制粘贴即可）
```bash
export PATH=/opt/arm-gnu-toolchain-13.3.rel1-mingw-w64-i686-arm-none-eabi/bin:/usr/bin:/mingw64/bin:$PATH
export PYTHONUTF8=1
cd /e/ubuntu/stm32_micropython/quectel_bg95_reference_design\ \(1\)/quectel_bg95_reference_design/micropython/ports/stm32
script -c "make clean && make BOARD=STM32F413 V=1 -j4" build.log
tail -30 build.log
```

**注意**：
- 必须包含 `/usr/bin` 和 `/mingw64/bin`，否则 make 或 python 会报 command not found
- 使用 `script` 命令捕获完整输出到 `build.log`，避免终端截断
- `tail -30 build.log` 查看最后 30 行确认编译结果
- `V=1` 显示详细编译命令

### 编译成功标志
看到 `LINK build-STM32F413/firmware.elf` 和生成 `firmware.elf` 就成功了。

## 四、烧录固件

### 使用 STM32CubeProgrammer
1. 连接开发板（ST-LINK）
2. 打开 STM32CubeProgrammer
3. 选择 `firmware.hex` 文件
4. 点击 Download 烧录

固件位置：`micropython/ports/stm32/build-STM32F413/firmware.hex`

## 六、模块依赖关系

你的代码三层架构：
```
core（基础层）→ Drivers（驱动层）→ Modules（服务层）
```

所有层通过 EventBus 解耦，互相不直接调用，只通过事件通信。

## 七、常见问题

### Q: make: command not found
A: PATH 里缺少 `/usr/bin`。确保 export 命令包含它：
```bash
export PATH=/opt/arm-gnu-toolchain-13.3.rel1-mingw-w64-i686-arm-none-eabi/bin:/usr/bin:/mingw64/bin:$PATH
```

### Q: python3: No such file or directory
A: PATH 里缺少 `/mingw64/bin`。确保 export 命令包含它（见上方）。

### Q: 编译报 UnicodeDecodeError
A: 确保设置了 `export PYTHONUTF8=1`

### Q: import 报 ModuleNotFoundError
A: 检查 manifest.py 中的路径是否带目录前缀

### Q: SMS 不工作
A: 确认用的是最新固件源码（包含 mp_sms.c）

### Q: display_service 报 images 找不到
A: images.py 和 images1.py 需要手动放到 flash 文件系统上
