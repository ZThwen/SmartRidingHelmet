方案 B：Canvas 蓝点 + Polyline 共存

去掉 show-location，用 canvas 画蓝色圆点作为自定义 marker

核心原理

WeChat <map> 组件的 show-location 和 polyline 互斥。解决方案：去掉 show-location，用 canvas 画一个蓝色圆点图片，作为 marker 的 iconPath。

骑行前（未骑行）

show-location = true
显示手机 GPS 蓝点

无轨迹线

骑行中

show-location = false
polyline + 自定义蓝点 marker

轨迹线 + canvas 蓝点

实现步骤

  1. index.wxml 添加隐藏 <canvas type="2d">
  2. index.js onLoad 中 canvas 画蓝色圆点 → 导出临时文件
  3. map-service.js buildMarker 接受 iconPath 参数
  4. index.js onData 中传入 _dotIconPath
  5. index.wxml 去掉 show-location

关键技术点

1

Canvas 2D 画蓝点

用 <canvas type="2d"> 画蓝色实心圆 + 白色边框 + 外圈光晕，导出为临时文件作为 marker iconPath

2

时序保证

canvas 画完 → wx.canvasToTempFilePath → 存储路径 → 后续 onData 使用。需确保在第一个 BLE 数据到达前完成

3

位置更新

每次 onData 时用最新 GPS 坐标更新 marker 的 latitude/longitude，通过 setData 一次完成

4

降级策略

如果 canvas 导出失败（极端情况），buildMarker 返回空数组，轨迹线仍可显示，只是没有蓝点
